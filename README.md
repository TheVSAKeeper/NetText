# NetText

Текстовый редактор и просмотрщик больших логов для Windows x64 на .NET 11 (NativeAOT), Win32/GDI и Scintilla + Lexilla.

> [!NOTE]
> **Дисклеймер: «перепишем на C#» в эпоху «перепишем всё на Rust»**
>
> Этот проект – эксперимент и оммаж оригинальному редактору [RustText](https://github.com/Illson/RustText). Он появился из спортивного интереса на фоне моды «перепишем весь мир на Rust»: хотелось посмотреть, что выйдет, если пойти против течения и перенести свежий Rust-проект на .NET NativeAOT.
>
> - Архитектура, sparse-индекс логов, безопасная обрезка, сессионный журнал и UX – заслуга **RustText**. NetText использует Win32/GDI, Scintilla и Lexilla для редактора и GDI для просмотра логов.
> - NetText 2.3.0 переносит возможности [RustText 2.3.0](https://github.com/Illson/RustText/tree/d5e53ed245becbbfe79e8f6f15ce16cda52ebd59) в нативный редактор Win32/Scintilla NativeAOT. Сессии, рабочие пространства, настройки, архив черновиков, снимки и пакеты обновления NetText хранятся в собственном формате.
> - В версии 2.x сам RustText переписан на C# (`.NET 11` NativeAOT + Avalonia 12 + AvaloniaEdit 12), поэтому замеры ниже сравнивают официальный релиз **`RustText v2.4.0`** (`b2e9383`) без правок с **`NetText 2.3.0`** на одном и том же `.NET 11` NativeAOT.

## Работа в редакторе

- **Темы и окно**: меню «Тема» переключает палитры «Фокус», «Неон» и «Vice City» (градиент и силуэты пальм в шапке, тёмная рамка и диалоги). Номера строк сгруппированы точками (`1.123.123`), компактная миникарта показывает отступы, тонкий скруглённый скроллбар вынесен правее миникарты. Полоса вкладок прокручивается колёсиком с тонким индикатором, двойной щелчок по вкладке закрывает её (с выбором левого соседа), по пустому месту – создаёт новую.
- **Мультикурсор, ссылки и жесты**: `Ctrl+Click` / `Alt+Click` добавляют и снимают курсоры, `Ctrl+Alt+↑/↓` добавляют курсор по вертикали, `Alt` + перетаскивание выделяют столбец, `Ctrl+D` и `Ctrl+Shift+L` выделяют совпадения (до 10 000 курсоров), `Ctrl+V` распределяет строки по курсорам, `Esc` сворачивает к основному курсору. `Ctrl+Shift+Click` открывает ссылки, `Ctrl+X` без выделения вырезает текущую строку, `Ctrl+колёсико` и `Ctrl+0` управляют масштабом (сохраняется в настройках). Строка состояния показывает строку, число выделенных символов и курсоров.
- **Поиск и JSON / JSONL**: `Ctrl+F` запускает автопоиск для файлов меньше 1 ГиБ (и ручной для ≥ 1 ГиБ), поддерживает «Только текущее», сворачиваемый «Список», «Найти все» (переводит совпадения в мультикурсор) и замену `Ctrl+H`. Файлы `.json`, `.jsonl` и `.ndjson` (и JSONL-логи по содержимому) подсвечиваются, проверяются построчно и форматируются по `Ctrl+Shift+J`.
- **Логи, уровни, постраничное редактирование и консоль**: `.log` и распознанные `.txt` до 100 МиБ открываются в режиме лога; для файлов больше 100 МиБ выводится выбор режима с «Запомнить выбор»; файлы больше 50 МиБ редактируются постранично (атомарное сохранение через временную копию). Панель «Уровни…» фильтрует строки по важности и в просмотре лога, и поверх несохранённого буфера редактора. Для логов от 128 МиБ полная индексация включается по запросу в «Действия ▾». «Файл → Подключиться к консоли…» открывает живую вкладку лога классической консоли Windows по PID или имени процесса.
- **Окна, рабочие пространства, история и архив**: вкладку можно вынести перетаскиванием в отдельное окно (с предпросмотром и отменой по `Esc`), а один файл редактировать совместно в нескольких окнах. Квадратный значок слева вверху открывает рабочие пространства (свой символ и цвет рамки, «Управление…», восстановление удалённых, изолированное «Пустое окно»). На главной показаны сворачиваемые разделы «Недавние файлы», «Закрытые файлы» и «Призрачные вкладки» с размерами и удалением (`×`). Закрытые черновики архивируются в ZIP по расписанию («Архив черновиков…»), скрытые вкладки выгружаются при простое (`◷`), файлы с диска автообновляются с выносом несохранённых правок в черновик, а в «Версии файла…» доступен diff с текущим текстом.
- **Инструменты, настройки и обновления**: команды «Инструменты» сгруппированы по разделам; «Настройки…» объединены в окно с боковым меню. Обновления проверяются при запуске и раз в час на GitHub (`TheVSAKeeper/NetText`), показывают «Что нового» и историю выпусков и проверяют SHA-256 перед перезапуском. При сохранении файла на рабочем столе восстанавливается позиция значка в Проводнике.

## Запуск и сборка

Для публикации нужны .NET 11 SDK, PowerShell 7 и Visual Studio Build Tools с C++ x64 и Windows SDK. Первая публикация скачивает архивы исходников Scintilla 5.6.9 и Lexilla 5.5.5, сверяет SHA-256 и собирает статические библиотеки в `native\obj\static-editor`. Результат – один `publish\NetText.exe` с обоими редакторными компонентами.

```powershell
dotnet publish src\NetText\NetText.csproj -c Release -r win-x64
pwsh -NoProfile -File tools\Package-NetText.ps1 -OutputDirectory dist\release
```

Для `dotnet build` и тестов положите x64-версии `Scintilla.dll` (5.6.9) и `Lexilla.dll` (5.5.5) в `native\win-x64\`.

```powershell
dotnet test tests\NetText.Tests\NetText.Tests.csproj -c Release
```

## Воспроизведение сравнения

Чтобы запустить полный парный замер на своём ПК (потребуется клон [RustText](https://github.com/Illson/RustText) и 12 GiB свободного места):

```powershell
git clone https://github.com/Illson/RustText.git ..\RustText
pwsh -NoProfile -File tools\Measure-AvaloniaComparison.ps1
```

Для быстрого проверочного прогона на малых файлах добавьте `-Smoke -Iterations 2`. Пересчитать `docs/comparison.md` из опубликованных данных `docs/comparison-raw.json` (для отдельной копии укажите `-ReportPath`):

```powershell
pwsh -NoProfile -File tools\Measure-AvaloniaComparison.ps1 -RenderFromRawJson
```
