# NetText и RustText 2.4.0

Полный сценарий. Windows x64, .NET SDK 11.0.100, по 6 пар на сценарий.

- NetText: `350c7fcccd29701f6de519693e4ebb13247af8ce`. RustText: `b2e93831443d4cbe72ff33d20cd8a61bace2a0d8`.
- Размер EXE NetText 14560256 байт, RustText 50188800 байт. RustText дополнительно извлёк 18839080 байт DLL.
- Сырые наблюдения, окружение, хеши бинарников и входов – в [comparison-raw.json](comparison-raw.json).
