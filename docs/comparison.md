# NetText и RustText 2.6.1

Полный сценарий. Windows x64, .NET SDK 11.0.100, по 6 пар на сценарий.

- NetText: `c49427e24f9b36de23d003df478c7930742bb8a3`. RustText: `6e7687d427ab2179b7466071309389e35cb5a87b`.
- Размер EXE NetText 14560256 байт, RustText 50802176 байт. RustText дополнительно извлёк 18839080 байт DLL.
- Сырые наблюдения, окружение, хеши бинарников и входов – в [comparison-raw.json](comparison-raw.json).

## GUI

Окно обнаружено внешней пробой Windows, ответ означает успешный `WM_NULL`, `readyMs` – готовность открытого файла (маркер NetText / запись `recent-files.json` RustText). Память снята примерно через 2000 мс от запуска процесса. Cold относится к кэшу приложения, состояние кэша ОС естественное.
